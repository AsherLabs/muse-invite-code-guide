Muse 是 Meta 推出的个人 AI 智能体：不是聊天机器人，而是能自己打开网页、处理邮件、订行程的 AI 助理，每位用户还配一台专属云端电脑，手机关了它也在后台干活，并且有长期记忆，越用越懂你。目前只对美国、加拿大开放，大陆直接注册会卡住。这篇把走通的流程和三个大坑一次讲清，照着做，10 分钟搞定。

## 准备工作

- 一个常用邮箱：建议 Gmail 或 Outlook，国内部分邮箱可能拦截 Meta 的验证邮件，收不到验证码。
- 注册全程免费，不需要付费订阅。
- 邀请码必须在注册后 **48 小时内**兑换，过期作废（兑换方法在第四步）。

## 第一步：打开注册页，网络环境要在美加区

打开 https://muse.ai/join 。Muse 目前仅面向美国、加拿大年满 18 岁的用户开放，系统会判断访问地区：注册这一步，你的网络出口要在美国或加拿大，否则会提示「Muse 尚未在你的国家或地区开放」，或被放进等候名单（Waitlist）。

注意：**如果某个邮箱已经在非美区网络下打开过 Muse、进了等候名单**，社区里不少人的经验是换线路也很难再进去，更稳妥的做法是换一个全新邮箱，在美区网络下重新注册（Meta 没有公布官方规则，这条来自用户反馈，不保证一定成功）。

## 第二步：邮箱注册

输入邮箱，查收验证码并填写，再按提示填写生日等基本信息（Muse 要求年满 18 岁）。账号统一由 Meta Accounts Center 管理，一个账号长期使用，建议用你长期在用的邮箱。

## 第三步：年龄验证（三个官方选项，三选一）

注册过程中可能被要求验证年龄。**不是每个人都会碰到**：网络环境比较干净时，有机会直接跳过；环境被判定不够纯净时会被强制要求。碰到了也别慌，官方给了三条路：

1. **绑定 Instagram 账号**
2. **绑定 Facebook 账号**
3. **信用卡验证**

不想绑卡的话，就绑定自己正常在用的 Facebook 或 Instagram 账号，实测最省事，轻松就能过。

**走信用卡的注意事项（重点看）：**

- 这是**预授权冻结 1 美元**，用来确认你已成年，**不是扣款，也不是订阅**，页面写明 **5–7 个工作日内退回**。
- 国内银行发行的 Visa、Mastercard 多数能通过；部分虚拟卡会失败。
- 填表时「国家或地区（Country or region）」保持选 **United States**，ZIP code 填一个**真实存在的美国邮编**，地址与地区冲突可能触发风控导致验证失败。
- 验证失败不要反复提交，容易触发风控。先按页面提示检查填写信息，实在过不去就等几天再试。

## 第四步：注册成功后，立刻兑换邀请码（48 小时窗口）

注册一成功，先别急着体验，第一件事是兑邀请码：

1. 在**你自己的浏览器或手机 App** 里打开 Muse（注意：不要在 Muse 的云端浏览器里输入邀请码）；
2. 进入**设置（Settings）→ 通用（General）→ Redeem invite code（兑现邀请码）**；
3. 输入邀请码 **D68F0N**，提交；
4. 兑换成功后，10 亿 tokens 立即到账，在**设置 → Usage（使用情况）**里能看到余额。

**为什么强调立刻兑**：邀请码只能在加入后的 48 小时内兑换，过期作废，而且每人只能兑换一次别人的码。

**兑换失败的三个常见原因**：① 已经超过注册后 48 小时；② 这个码已经被用满 30 次；③ 你已经兑换过其他人的码了。

## 注册完成后的使用提示

- **日常使用不需要一直在美区网络**：用户反馈注册成功后换回日常网络也能正常使用。建议保持网络环境稳定，不要频繁在不同国家的出口之间切换，减少重复验证和风控。
- **手机 App**：iPhone 需要美区 Apple ID 才能在 App Store 下载；安卓非美区 Google Play 可能装不了。装不了就先用网页版 muse.ai，功能完整。
- **电脑客户端**：没有 Windows 官方版，Windows 直接用网页版即可（可以用浏览器装成桌面应用）；Mac 官方版只支持 Apple 芯片（M 系列），需要 macOS 14 或更新版本，Intel 芯片的 Mac 请用网页版。

## 常见问题

**Q：注册要花钱吗？那个 1 美元是什么？**
不要钱。1 美元是年龄验证走信用卡时的预授权冻结，确认成年用，5–7 个工作日退回。不想用卡就绑 Instagram / Facebook。

**Q：显示「区域不可用」或进了等候名单怎么办？**
先检查注册时的网络出口是否在美加区。如果邮箱之前在非美区网络下打开过 Muse，参考第一步里的社区经验：换全新邮箱、在美区网络下重新注册。

**Q：邀请码会让别人看到我的聊天记录吗？**
不会。每个人邀请到的助手都是独立的，邀请关系不共享任何聊天内容。

**Q：10 亿 tokens 是什么？**
是 Muse 的使用额度。免费版每周有基础额度并自动重置；邀请奖励的 10 亿 tokens 永久不过期，额外可用。
